OUR PURPOSE

Good planning makes
great memories.

Campus Events is a college event management website created to keep event information clear and easy to access. Students can browse the event calendar, while organizers can create, update, view, and remove event records.

The site uses a Node.js and Express server to connect the website to a MySQL database, so event details are read from and saved to your own dataset.
